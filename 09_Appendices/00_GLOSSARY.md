# 1. Introduction

This glossary provides definitions for the technical, educational, architectural, artificial intelligence, software engineering, deployment, and operational terminology used throughout the CogniLearn AI documentation.

Its purpose is to establish a common vocabulary that promotes clarity, consistency, and effective communication among all project stakeholders.

---

# 2. General Terms

| Term | Definition |
|------|------------|
| Adaptive Learning | A learning methodology that dynamically personalizes educational content according to learner performance, ability, and mastery. |
| Assessment | A structured evaluation used to measure learner knowledge, understanding, or competency. |
| Assessment Item | An individual question, problem, or activity used within an assessment. |
| Assessment Item Repository | A centralized collection of assessment items used to generate adaptive assessments. |
| Authentication | The process of verifying a user's identity before granting access to the system. |
| Authorization | The process of determining the permissions assigned to an authenticated user. |
| Course | A collection of related learning modules designed to achieve specific educational objectives. |
| Module | A logical subdivision of a course containing related learning topics. |
| Topic | A specific subject or concept taught within a module. |

---

# 3. Educational Intelligence Terms

| Term | Definition |
|------|------------|
| Educational Intelligence | The decision-making layer responsible for learner assessment, adaptation, recommendation, and instructional planning within CogniLearn AI. |
| Assessment Intelligence | The subsystem responsible for conducting adaptive assessments and evaluating learner performance. |
| Learning Intelligence | The subsystem responsible for analyzing learner responses and estimating knowledge mastery. |
| Adaptive Intelligence | The subsystem responsible for selecting personalized learning pathways and recommendations. |
| Teaching Intelligence | The subsystem responsible for preparing instructional context before invoking AI-generated educational content. |
| Teaching Context | Structured instructional information generated by Educational Intelligence and provided to the AI Service Layer. |
| Topic Mastery | A numerical estimate representing a learner's understanding of a particular concept or topic. |
| Learning Path | A personalized sequence of learning activities generated according to learner needs and mastery levels. |
| Knowledge State | The estimated understanding of a learner across one or more concepts based on historical performance. |

# 4. Artificial Intelligence Terms

| Term | Definition |
|------|------------|
| Artificial Intelligence (AI) | Computer systems capable of performing tasks that typically require human intelligence. |
| Large Language Model (LLM) | A machine learning model trained on extensive text datasets to understand and generate natural language. |
| Prompt | Structured input provided to an LLM for generating educational content. |
| Prompt Engineering | The process of designing prompts that produce accurate, relevant, and safe AI-generated responses. |
| AI Service Layer | The abstraction layer responsible for securely communicating with external AI providers while remaining independent of educational decision-making. |
| Gemini | Google's generative AI model used as the primary AI provider within CogniLearn AI. |
| AI Provider | An external platform that offers generative AI capabilities, such as Gemini, OpenAI, Claude, or other compatible models. |

# 5. Learning Algorithm Terms

| Term | Definition |
|------|------------|
| Item Response Theory (IRT) | A psychometric framework used to estimate learner ability based on assessment responses. |
| Theta (θ) | The estimated learner ability value calculated using Item Response Theory. |
| Bayesian Knowledge Tracing (BKT) | A probabilistic model used to estimate learner knowledge over time based on observed responses. |
| Mastery Score | A quantitative measure of learner proficiency in a specific topic. |
| Difficulty Level | An estimate of how challenging an assessment item is relative to learner ability. |
| Bloom's Taxonomy | A hierarchical framework for classifying educational learning objectives by cognitive complexity. |

# 11. Architectural Principle

The following architectural principle governs the entire CogniLearn AI platform:

> **Educational Intelligence drives Teaching Intelligence.**

Educational Intelligence is responsible for determining:

- What should be taught.
- When it should be taught.
- Why it should be taught.
- Which teaching strategy should be applied.

Teaching Intelligence transforms these educational decisions into structured teaching context.

The AI Service Layer forwards this context to the selected Large Language Model, which is responsible only for generating instructional content.

Therefore, the Large Language Model never determines educational strategy or learning decisions.
