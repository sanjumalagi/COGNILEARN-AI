# 14. Citation Style

This project follows the **IEEE citation style**.

General format:

```
[Reference Number] Author(s), "Title," Publisher/Journal, Year.
```

In-text citations should appear as numerical references enclosed in square brackets.

Example:

```
Adaptive learning techniques have been widely studied [9].

Item Response Theory is commonly applied in computerized adaptive testing [10].

Knowledge Tracing supports learner modeling [12].
```
