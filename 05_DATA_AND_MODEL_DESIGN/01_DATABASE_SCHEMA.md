# 1. Introduction

The Database Schema defines the persistent data storage for CogniLearn AI. It specifies the entities, attributes, relationships, and constraints required to support learner modeling, adaptive assessments, personalized recommendations, learning paths, teaching strategies, AI interactions, and analytics.

The schema follows relational database principles to ensure data integrity, consistency, scalability, and maintainability while supporting the Educational Intelligence layer.

---

# 2. Objectives

The Database Schema aims to:

- Store learner information.
- Manage educational content.
- Record assessments and learner responses.
- Support adaptive learning algorithms.
- Maintain learner progress.
- Store AI teaching interactions.
- Enable educational analytics.
- Preserve referential integrity.

---

# 3. Database Design Principles

The schema follows these principles:

### Normalization

Data redundancy is minimized through relational design.

---

### Integrity

Primary keys, foreign keys, and constraints ensure consistent data.

---

### Scalability

The schema supports increasing learners, courses, and assessments.

---

### Modularity

Each entity represents a single educational responsibility.

---

### Extensibility

Future educational algorithms and AI providers can be integrated without redesigning the database.

# 7. Database Constraints

The schema enforces:

- Primary Key constraints
- Foreign Key constraints
- NOT NULL constraints
- UNIQUE email addresses
- Cascade updates where appropriate
- Restricted deletes for educational records

---

# 8. Indexing Strategy

Indexes should be created on:

- user_id
- student_id
- topic_id
- assessment_id
- item_id
- mastery_score
- ability_theta
- created_at

These indexes improve query performance for adaptive learning operations.

# Guiding Principles

> Every entity should represent a single educational responsibility.

> Database design should support Educational Intelligence before AI interaction.

> Data integrity is essential for reliable adaptive learning.

> Relationships should reflect real educational processes.

> The schema should remain modular, scalable, and extensible.

> Educational Intelligence drives Teaching Intelligence.
