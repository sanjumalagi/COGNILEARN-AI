# 1. Introduction

The Mastery Engine evaluates a learner's current level of understanding by combining evidence from the Item Response Theory (IRT) Engine and the Bayesian Knowledge Tracing (BKT) Engine.

While IRT estimates overall learner ability and BKT estimates mastery of individual knowledge components, the Mastery Engine integrates these outputs to produce a comprehensive representation of learner proficiency.

This representation forms the educational foundation for recommendation generation, adaptive sequencing, and AI-assisted teaching.

---

# 2. Objectives

The Mastery Engine aims to:

- Evaluate learner mastery across topics.
- Aggregate evidence from multiple learner modeling algorithms.
- Identify mastered and non-mastered concepts.
- Detect learning gaps.
- Generate learner mastery profiles.
- Support personalized educational decisions.
- Provide educational intelligence for downstream adaptive engines.

---

# 3. Purpose within CogniLearn AI

The Mastery Engine answers the following question:

> **"What does this learner currently know, and what still requires improvement?"**

Instead of relying on a single assessment score, the engine evaluates mastery using accumulated educational evidence collected throughout the learner's interaction with the platform.

The engine produces the following outputs.

| Output | Description |
|---------|-------------|
| Topic Mastery | Mastery level for each topic |

| Mastery Profile | Overall learner knowledge representation |

---

# 7. Educational Mastery Model

The Mastery Engine integrates evidence from multiple educational sources rather than relying on a single metric.

The evaluation considers:

- Learner ability (IRT)
- Concept mastery probability (BKT)
- Assessment performance
- Learning history
- Topic completion
- Learning outcome achievement

The resulting mastery profile reflects the learner's current educational state.

---

# 8. Mastery Levels

The engine classifies mastery into educational categories.

| Level | Description |
|---------|-------------|
| Not Started | No evidence available |
| Beginner | Limited understanding |
| Developing | Partial understanding |
| Proficient | Consistent performance |
| Mastered | Demonstrated strong understanding |

These categories are configurable and may evolve as the educational model matures.

# 10. Processing Steps

The Mastery Engine performs the following sequence:

1. Retrieve learner ability estimate.
2. Retrieve concept mastery probabilities.
3. Evaluate each learning outcome.
4. Aggregate topic-level evidence.
5. Identify mastered concepts.
6. Detect learning gaps.
7. Build learner mastery profile.
8. Store updated mastery information.
9. Forward the profile to the Recommendation Engine.

---

# 11. Learner Mastery Profile

The Mastery Profile represents the learner's current educational state.

A profile includes:

- Overall learner ability
- Topic mastery
- Learning outcome mastery
- Weak concepts
- Strong concepts
- Recently learned concepts
- Pending learning objectives

The profile is continuously updated after each assessment interaction.

The Mastery Engine should:

- Handle multiple topics efficiently.
- Maintain learner consistency.
- Support real-time adaptive learning.
- Scale across large learner populations.

The Mastery Engine provides:

- Comprehensive learner modeling.
- Topic-level educational intelligence.
- Explainable mastery evaluation.
- Personalized learner profiles.
- Improved adaptive recommendations.
- Better learning analytics.
- Continuous progress monitoring.

---

# 17. Limitations

Current implementation limitations include:

- Depends on the quality of IRT and BKT outputs.
- Does not explicitly model concept dependencies.
- Uses configurable mastery thresholds.
- Assumes learning outcomes are clearly defined.

Future versions may include:

- Competency-based mastery evaluation.
- Cognitive diagnostic models.
- Hierarchical concept graphs.
- Knowledge dependency analysis.

---

# 18. Future Enhancements

Potential enhancements include:

- Dynamic mastery thresholds.
- Learning outcome weighting.
- Cross-course mastery analysis.

- Explainable educational analytics.
- Competency dashboards.

# 19. Relationship with Previous Algorithms

The Mastery Engine extends the learner modeling process.

| Algorithm | Responsibility |
|-----------|----------------|
| IRT Engine | Estimate learner ability |
| BKT Engine | Estimate concept mastery |
| Mastery Engine | Build comprehensive learner mastery profile |

Unlike IRT and BKT, which estimate specific learner characteristics, the Mastery Engine synthesizes these results into an educational representation that supports adaptive decision-making.

---

# 20. Summary

The Mastery Engine transforms learner modeling outputs into a comprehensive educational profile that reflects the learner's current understanding across topics and learning outcomes. By integrating ability estimates, mastery probabilities, and historical learning evidence, the engine provides a holistic view of learner progress.

This mastery profile becomes the primary educational input for the Recommendation Engine, Learning Path Engine, and Adaptive Decision Engine, ensuring that subsequent instructional decisions are grounded in measurable learner evidence rather than isolated assessment results.

---

# Guiding Principles

> Mastery should be evaluated using multiple sources of educational evidence.

> Learner profiles should evolve continuously with new assessment data.

> Educational decisions should reflect demonstrated understanding rather than single assessment scores.

> Mastery evaluation should remain transparent and explainable.

> Comprehensive learner modeling enables effective adaptive learning.

> Educational Intelligence drives Teaching Intelligence.
