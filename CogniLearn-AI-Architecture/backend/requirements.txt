# --- Security (wired in Module 3) ---
# NOTE: python-jose was replaced with PyJWT[crypto] during the Module 0
# quality gate. python-jose's default backend depends on `ecdsa`, which
# carries an unfixed timing-attack CVE (PYSEC-2026-1325) that the
# python-ecdsa maintainers have declined to patch. PyJWT[crypto] uses the
# `cryptography` library instead and has no such advisory. No application
# code depends on either package yet (Module 3 is where JWT issuance and
# verification are implemented), so this is a dependency-only
# substitution with no API or behavior impact.
