# 1. Introduction

Experimental Evaluation provides scientific evidence that CogniLearn AI achieves its educational objectives. While previous testing phases verify software correctness, this phase evaluates whether the platform improves learning outcomes through adaptive assessments, Educational Intelligence, and AI-assisted instructional support.

The evaluation measures both technical performance and educational impact by comparing learner outcomes obtained using CogniLearn AI with those obtained using traditional learning approaches.

The results provide objective evidence supporting the effectiveness of the proposed adaptive learning framework.

---

# 2. Objectives

The experimental evaluation aims to:

- Measure learning improvement.
- Evaluate adaptive learning effectiveness.
- Assess Educational Intelligence performance.
- Evaluate AI-assisted instructional support.
- Measure learner engagement.
- Compare personalized learning with traditional approaches.
- Validate the overall educational value of the platform.

# 14. Threats to Validity

Potential threats include:

| Threat | Mitigation |
|--------|------------|
| Small sample size | Increase participant count |
| Participant bias | Random assignment |
| Learning variability | Comparable participant backgrounds |
| AI provider variability | Standardized prompts and evaluation |
| Network latency | Stable testing environment |
| Researcher bias | Standardized evaluation procedures |

Recognizing these limitations improves the credibility of the experimental results.
